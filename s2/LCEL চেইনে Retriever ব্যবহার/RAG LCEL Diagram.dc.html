LCEL চেইনে Retriever ব্যবহার

Retriever হলো একটা ব্রিজ — আপনার নিজের ডেটাকে LLM-এর সাথে যুক্ত করে, যাতে উত্তর আসে প্রকৃত ডকুমেন্ট থেকে।
chain.invoke "বাংলাদেশের রাজধানী কী?"
dict — parallel branch
"context"
retriever
প্রশ্নের সাথে মিল থাকা ডকুমেন্ট খুঁজে আনে → List[Document]
format_docs
ডকুমেন্টগুলোকে একটা টেক্সট ব্লকে জোড়া লাগায় → str
"question"
RunnablePassthrough()
মূল প্রশ্নটা অপরিবর্তিত রেখে পরের ধাপে পাঠায়।
দুটো শাখা একসাথে চলে, তারপর ফলাফল একটা ডিকশনারিতে মিলিত হয়।
prompt
{context} ও {question} বসিয়ে চূড়ান্ত মেসেজ তৈরি করে।
ChatAnthropic
দেওয়া কনটেক্সটের ভিত্তিতে উত্তর তৈরি করে → AIMessage
StrOutputParser
মেসেজ অবজেক্ট থেকে শুধু টেক্সট বের করে আনে → str
answer "বাংলাদেশের রাজধানী ঢাকা।"
chain.py
chain = (
    {
      "context": retriever
                 | format_docs,
      "question": RunnablePassthrough()
    }
    | prompt
    | llm
    | StrOutputParser()
)

answer = chain.invoke(
    "বাংলাদেশের রাজধানী কী?"
)
